# Product — Semantic Pair

Working name: **Semantic Pair**

Dual-remote brainstorm tool for two collaborators. Live AI cues show **semantic distance** (how far apart ideas are in meaning) and a **creativity-stage** label (e.g. diverge / converge) so pairs can stay aligned without killing novelty.

## Goals

- Two people brainstorm in parallel panels (Person A / Person B).
- Surface a continuous semantic-distance score (0–1) and a stage cue from both texts.
- Demo-first: mocked embeddings until a real embedding API is wired; realtime starts as in-memory / WebSocket stub (Supabase-ready interface later).

## Non-goals (MVP)

- More than two concurrent roles in v1.
