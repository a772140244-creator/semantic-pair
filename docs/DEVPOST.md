# Devpost blurb — Semantic Pair

**Semantic Pair** is a dual-remote brainstorm tool for two collaborators. Side-by-side idea panels show a live (mocked-for-demo) **semantic distance** score and a **creativity-stage** cue—diverge, explore, or converge—so pairs can stay creatively honest without losing each other.

Built for **Kiroween 2026** (Frankenstein): Next.js App Router + TypeScript, deterministic embedding mock, and a Supabase-ready realtime stub. Solo student entry by **ZhuoQI Yin**. The `/.kiro` steering, specs, and hooks are part of the deliverable.

**Stack:** Next.js, TypeScript, mock cues → real embeddings later, in-memory/WebSocket stub.
